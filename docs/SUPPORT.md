# Support

Use [`mss-boot-admin` GitHub issues](https://github.com/mss-boot-io/mss-boot-admin/issues)
for documentation defects, missing pages, broken links, and workflow clarification
requests. Include the affected site path and the source file under `docs/`.

Security reports must follow `SECURITY.md` and should not be filed as public
issues.

For suspected vulnerabilities, use the SECURITY policy FAQ in
`docs/docs/devops/security-policy-faq.md`. For Admin login failures, use
`docs/docs/admin/login-troubleshooting.md` before opening an issue.

Long-lived product decisions belong in `docs/docs/` or `docs/adr/`; historical
agent prompts belong in `docs/aigc/prompts/`; executable facts belong in `.mss/`.
