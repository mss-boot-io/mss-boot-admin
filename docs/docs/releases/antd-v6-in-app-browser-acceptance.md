## 验收中发现并关闭的问题

默认混合布局原先同时渲染顶栏品牌和侧栏品牌。原因是 V6 自定义
`menuHeaderRender` 覆盖了 Pro Layout 在 `mix` 模式下的默认抑制规则。
实现提交 `990a8406ad2e9be1b518f92c9f24cade49692b7c` 在混合布局关闭侧栏品牌，
并保留侧栏布局品牌与专用移动端头部。热更新后在同一内置浏览器复查，只剩顶栏一处品牌。

## 有意保留的边界

- 未在人工验收中实际修改个人密码，避免改变隔离验收账号；安全写路径由现有集成与 E2E 门禁承担。
- 隔离环境没有配置真实 OAuth 提供方，因此没有对外部平台发起解绑；本次确认空状态、入口条件和安全说明。
- 本记录不替代集中执行的 lint、单元/集成、Chromium E2E、生产构建、依赖与发布安全检查。
- 合并后若精确 `main` 提交、后端身份或发布配置变化，必须重跑受影响验收，不能复用本记录授权发布。
