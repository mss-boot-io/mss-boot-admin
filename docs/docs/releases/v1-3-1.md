## 为什么不能继续 v1.3.1

- 已公开的 Framework Tag、Release、Go Module 和工作流证据不可移动、覆盖或删除。
- 已存在的 Admin Tag 不能改指向修复提交，也不能在原版本上补发另一份内容。
- 流水线停止是正确的安全行为，不能用 `replace`、`GONOSUMDB` 或跳过独立解析绕过。
- 修复必须使用更高补丁版本、一个新的 merged-main 精确提交和重新生成的全部受影响证据。

## 恢复与回滚

该失败发生时，生产回滚基线仍是 v1.2.3；现在 v1.3.2 已完成全部公开发布与对账，
是当前稳定版，v1.2.3 是上一稳定回滚基线。不要把 `mss-boot/v1.3.1` 与任何
v1.2.3 Admin、前端或 Thin Host 混合为受支持发行包。
